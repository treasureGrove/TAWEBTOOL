# 小树林尸潮 (Grove Horde) — 进度与设计

## Intent

侧边栏可进入的 Three.js 第一人称射击小游戏：波次清理扑来的僵尸。
桌面端指针锁定操作，有连击/爆头/波次压力，服务器记录排行榜与个人最好成绩。

## Design brief

- **玩家幻想**：你是小树林防线教官，用脉冲步枪顶住一波波僵尸。
- **目标感觉**：干脆利落的街机枪感 + 爆头上头 + 尸潮压迫。
- **主谓词**：瞄准射击（hitscan）。
- **次谓词**：走位、冲刺、换弹、机瞄、拉开距离。
- **每 5–30 秒**：瞄准 → 点射/爆头 → 连击延续或被扑咬打断。
- **1–5 分钟变化**：尸潮强度、行走尸/疾行尸/吐酸尸配比、逼近速度递增。
- **失败/学习/重开**：HP 归零结束；结算显示命中率与击杀；一键重开。
- **奖励/风险**：连击倍率、爆头加分、波次清场奖励；打空断连击，近身撕咬与吐酸掉血。
- **高手差异**：优先爆头、拉开疾行尸、集火吐酸尸。
- **非目标（本切片）**：多人对战、复杂关卡编辑器、外链资产生成、手机完整体感。

## Core loop contract

玩家用 **瞄准射击** 清理 **波次构装体**，在 **敌方火力与连击计时** 下冒险；
成功给 **分数/连击/波次奖励**，失败是 **HP 耗尽**，结算后可立刻重开并上传成绩。

| 子句 | 代码落点 |
|------|----------|
| 动词映射 | pointer lock + 鼠标/键盘 intents |
| 目标可见 | HUD 波次/剩余目标/准星 |
| 首分钟压力 | 第 1 波即有射手构装体 |
| 奖励改状态 | 分数、连击倍率、波次推进、排行榜 |
| 失败有反馈 | 受击红闪、准星扩散、结算面板 |
| 重开快 | 结算后单键重开 |

## Level / encounter plan

- **空间**：圆形林间靶场，中央低台 + 环形掩体晶柱 + 四角靶架。
- **镜头**：第一人称，站立眼高；可看见四周威胁，晶柱提供短暂遮挡决策。
- **开局**：出生点南侧 → 第一决策「打环靶还是先压射手」→ 第一威胁波次 1 无人机 → 第一奖励连击/核心加分。
- **地标**：中央青绿信标、四角橙色靶架、外圈剪影树。
- **递进**：每波 +1~2 敌人；波次 3+ 引入速掠体；波次 5+ 射手射速提升。
- **恢复节拍**：波次间隙 2.5s 自动回少量 HP、补给弹药。
- **预兆**：敌人生成有落点光圈；敌方激光前 0.35s 有锁定线。

## Art / technical direction

- **锚点**：Valorant 靶场的战术清晰度 × 本站青绿玻璃拟态。
- **色板**：夜林底 `#071411`，墨字 `#e2e8f0`，主强调 `#26a884`，威胁橙 `#ff6b4a`。
- **字体**：UI 用站点衬线；HUD 数字用等宽。
- **视觉签名**：构装体晶格轮廓 + 准星命中反馈 + 波次清场扫光。
- **技术**：零构建静态页 + CDN Three.js r160；程序化几何/材质/WebAudio；自定义 AABB/球碰撞（街机）。
- **随机**：全部走 seeded RNG（mulberry32），测试钩子可固定 seed。

## Systems map

```
input → player → weapon(hitscan) → enemies/waves → vfx/audio → ui/hud
                              ↘ scores(local + /api/scores)
```

## Score API

- `GET /api/scores?game=grove_range&limit=20` — 排行榜
- `POST /api/scores` — 提交 `{name,score,wave,accuracy,kills,durationMs}`
- 存储：`data/game_scores/entries.json`（gitignore）
- 失败时前端回落 localStorage
