# 铅之圣咏 · 浏览器小样

当前制作方向已切换到 Web。双击上一级目录的 **启动网页版.cmd** 即可打开游戏。网址是 `http://127.0.0.1:4173/`。这是本机试玩地址，无法在另一台电脑上直接访问。

这版聚焦 **三天、九位来客、一次完整的租金结算**，预计 10—20 分钟。使用正常的实时 3D 金属、玻璃、阴影与光照，无 PS1 像素化或全屏扫描线。废土风格由工业设备、旧黄铜、修院告示、绿色终端和柜台布景构成。

## 开始玩

1. 左下工具柜选择装备。工具与商品共用 4×3 的背包，开门后工具柜上锁。
2. 点“翻牌 · 开门营业”。左边检查，右边留存证据，每人最多三次，阅读不限时。
3. 决定是否收购。收购直接付钱、占格，但还没有签发认证。
4. 三位来客走完后，选择背包里的商品，复核证据，再选“签为真品”或“不作认证”。
5. 选择买家，点击“签字交付”。回收、公开证据不要求真品认证。
6. 点“熄灯 · 结算”。三天结束后会得到经营与去向共同决定的尾声。

拖动背包可以换位置。也可以点选物品，再点击空格。按 R 旋转。拖动 3D 柜台区域或点旋转按钮，可以查看商品。右上角有玩法说明、账本和音效开关。音效默认关闭。

进度只存到这台电脑当前浏览器的本地存储。换浏览器不会继承；清除站点数据会清除进度。重新开局有确认步骤。

## 验证什么

第一次建议用默认工具玩，不要先看代码中的物品真相。最值得反馈的是：

- 什么时候背包真让你放弃了一笔想做的生意？
- 证据是否足以让你判断，还是只能猜？
- 诊所的低价和民兵的高价，是否让你犹豫？

收购与认证已分开，不再使用旧 Godot 版容易误解的“未认证收购”按钮。不同渠道报价前，必须主动选择是否认证。认证假货会退回收入并罚 6 币；普通渠道的污染品会追加处置费；不确定时仍可选择残料交付或密封回收。

## 当前范围

- 原创的正常 3D 柜台、仪器、人物半身模型和 13 种工具/商品轮廓，直接由 Three.js 构建。
- 九件商品与 45 条鉴定证据，三日通告，部分对白响应此前的交易。
- 金钱、占格、形状旋转、认证退款、危险品与六条已验证可达的结局路线。
- 桌面完整柜台布局，小屏采用上下排列。支持鼠标、键盘与触摸整理。

人物仍使用同一个原创程序模型，不是写实扫描角色；本版用于验证核心玩法，不是完整商业美术交付。此目录只包含 Web 版，不依赖 Godot。

## 本地开发

无需安装依赖或构建，Three.js 0.180.0 已包含在 `dist/vendor`，保留 MIT 许可证。可以用 Node.js 运行：

```
node server.mjs
node --test tests/engine.test.mjs
```

主要文件：`dist/engine.js` 是规则，`dist/data.js` 是内容，`dist/world.js` 是 3D，`dist/app.js` 是交互，`dist/style.css` 是界面。`dist` 是可由任何静态 Web 服务托管的完整目录。

本次已执行规则与完整路线测试、JavaScript 语法检查、HTTP 和本地资源引用检查。未执行浏览器截图或视觉自动验收；也没有宣称验证过不同显卡的实际表现。

提供了可选的 WebMCP 读状态与检查工具，浏览器支持时注册。不支持时不影响游戏。本环境没有可用的 WebMCP 合同验证上下文，故未声称验证过该集成。

`dist/` 可以直接部署在现有网站的静态目录中。GitHub 中保存源码不等于线上服务器已经完成部署。

3D 实现参考 [Three.js 官方文档](https://threejs.org/docs/)。全部游戏文案与场景属于此原型；不含《辐射》的模型、标志或角色素材。
