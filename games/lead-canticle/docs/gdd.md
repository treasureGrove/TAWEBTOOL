## 1. 核心体验(玩家到底在爽什么)

> **"我看出来了。"**

玩家扮演的不是战士,是**鉴定师**。唯一的超能力是**眼力**:在一堆残骸里分辨出什么是真的、什么是谎话、什么会害死人。

三根绳子同时拉着玩家,构成全部张力:

1. **钱** —— 房租每周上涨,欠租就客流下降,进入死亡螺旋(和《深空当铺》同构)
2. **真伪** —— 鉴定可能出错,出错要赔钱、赔命、赔掉一条街的人心
3. **立场** —— 你把手里的东西交给谁,决定了这片废土的下一次战争由谁打赢

**关键设计原则:整个游戏没有一场战斗。** 战争永远发生在柜台之外,你只在柜台上看到战争的垃圾,以及把垃圾当宝贝的人。这就是反战主题的表达方式 —— 不是喊口号,是不给你扣扳机的机会。

## 2. 核心循环

**一天 = 一个回合,约 8~12 分钟。四个阶段:**

### 阶段一:开门前 · 整理(约 2 分钟)
- 把今天要用的**鉴定工具**和待售**商品**放进有限的格子
- 决定今天挂什么**招牌**(吸引不同客群:修道院信使 / 商队 / 拾荒者 / 民兵 / 治安队)
- 检查**身体状态**:辐射值、疲劳、手抖(手抖会降低鉴定精度)

### 阶段二:营业 · 鉴定(约 5 分钟 · 核心)
3~5 位客人依次上门。每位客人是一道谜题:

```
客人提出物品
   ↓
玩家用工具鉴定(消耗时间 / 消耗工具耐久 / 损伤物品)
   ↓
真相 + 证据充分度 → 玩家做出判断
   ↓
给估价 → 客人还价 / 设局 / 亮出身份
   ↓
决定:收下 / 拒绝 / 举报 / 睁一只眼闭一只眼
   ↓
后果(钱、声望、身体、剧情旗标)
```

### 阶段三:结算(约 1 分钟)
收入、支出(燃料/食物)、房租倒计时推进、四派系声望变化、身体状态结算。

### 阶段四:夜里 · 日志(约 2 分钟)
- 写**日志**(承担叙事推进 + 自动存档)
- 分配技能点(眼力/忍耐/口才/医术)
- 收到派系的信、威胁、或者一件来路不明的包裹 → 下一天

## 3. 鉴定系统(本作的"审核",也是《请出示证件》的对应物)

### 3.1 每件物品的隐藏属性
| 属性 | 说明 |
|---|---|
| **真伪** | 真品 / 仿品 / 现代复制品。**关键反转:有些"仿品"比真品贵** —— 因为真品只是某个失败的原型 |
| **年代** | 核前 / 烈焰洪水之后 / 教会抄本时期 |
| **危险性** | 辐射 / 生物 / **认知危害**(读了这个名字的人会开始做同一个梦) |
| **市场价** | 按派系浮动(教会按"圣物"给价,民兵按"武器"给价,同一件东西差价 5 倍) |
| **来历** | 有些物品带着"身份",卖出去等于卖掉一个人 |

### 3.2 鉴定工具(全部占背包格子 —— 这是核心机制)
| 工具 | 作用 | 耗时 | 占格 | 副作用 |
|---|---|---|---|---|
| 放大镜 | 看铭文、印刷工艺 | 短 | 1 | 无 |
| 酸滴 | 测金属年代 | 中 | 1 | **损伤物品,降低售价** |
| 天平 | 验金、验铅封 | 短 | 2 | 无 |
| 辐射计 | 测危险度(保命) | 中 | 2 | 无 |
| 圣徒名录 | 查教会认证的真品编号 | 长 | 2 | 客人不耐烦 |
| 沙漏 | 延长客人等待时间 | — | 1 | 客人怀疑你在骗他 |
| 钝刀 | 拆开外壳看内芯 | 短 | 1 | **不可逆,拆了就不值钱** |

> ### ⚠️ 这是全作最重要的设计
> **工具占格子,商品也占格子。你永远带不齐所有工具。**
> 所以你**只能选择信任哪一部分证据**。
>
> 带齐工具 → 没地方放商品 → 没东西可卖
> 带满商品 → 鉴定全靠猜
>
> **"背包管理"不是外挂玩法,它就是鉴定系统本身。** 玩家每次开门前整理背包,实际上是在选择今天愿意冒哪一种风险。

### 3.3 判定与代价
- 证据充分 → 判定可靠
- 证据不足 → 游戏**不惩罚你"没看出来"**(不弹"失败"),但**后果照常发生**:客人离开、派系记账、假货流通出去、某个人因此死掉
- **没有"正确选项",只有"你愿意承担哪个后果"** —— 这是从 Papers, Please 学来的最重要一课

### 3.4 客人压力(时间要素)
每位客人有耐心值(由沙漏延长)。三件事同时发生:客人在催、燃料在烧、房租在涨。玩家的失误大多不是"看不出来",而是"来不及看"。

## 4. 模拟经营系统

### 4.1 四类资源
| 资源 | 获取 | 消耗 | 归零后果 |
|---|---|---|---|
| **铁币**(钱) | 交易 | 房租、进货、贿赂、买药 | 破产结局线 |
| **燃料/食物** | 买、以物易物 | 每天固定消耗 | 无法营业,身体恶化 |
| **声望**(四派系独立, -100~+100) | 交易、举报、站队 | 得罪、食言、卖假货 | 暴民私刑 / 被查抄 |
| **身体**(辐射 / 疲劳 / 手抖) | 休息、药物 | 鉴定、危险物品、熬夜 | 手抖→鉴定失准;辐射→结局分支 |

**四派系**:修道院(保存知识)· 商队(只想赚钱)· 民兵(想用知识打仗)· 治安队(维持秩序,也就是维持现状)

### 4.2 房租死亡螺旋(直接对标《深空当铺》)
- 每 7 天租金上涨一次,曲线可调
- 欠租 → 店铺失修 → 客流下降 → 收入下降 → 缺口更大 → 只能接高风险单
- **不是为了让你赢,是为了让你在最难的时候暴露本性**

### 4.3 库存 = 背包 = 货架(一套网格系统,两个存放点)
| 存放点 | 优点 | 缺点 |
|---|---|---|
| **店内货架** | 容量大、可直接卖给客人 | 被举报会被查抄,全部没收 |
| **随身背包** | 隐蔽,搜查时查不到 | 容量小;被打劫会全丢 |
| **暗格** | 最安全 | 格子极少;被搜出后果最重 |

- 违禁品(民兵武器、认知危害物品、教会禁书)必须藏
- 藏匿位置的选择 = 每天一次小型赌博

### 4.4 职业流派(多周目动力)
参考《深空当铺》的多流派,但换成废土职业:
**抄本鉴定师**(靠教会关系) / **拾荒商人**(靠低价进货) / **军械修复匠**(靠民兵订单) / **药剂师**(靠制造成瘾性止痛药) / **收尸人**(靠遗物,道德代价最高)

每种流派:独特盈利方式 + 自带致命隐患(和《深空当铺》完全同构的设计语言)。

### 4.5 失败不是 Game Over,是结局
破产、被查抄、被私刑、辐射病死 —— 全部通向**一个真正的结局**,而不是"重开"。这让失败也有叙事价值。

## 5. 叙事与结局:双轴结局系统

### 5.1 两个轴
- **X 轴 = 钱**:破产 ←→ 买下这间店铺 / 富可敌国
- **Y 轴 = 立场**:你把知识交给了谁
  - 交还修道院(保存)
  - 卖给民兵(武器化)
  - 私藏(占有)
  - 销毁(同归于尽)

### 5.2 结局矩阵(8~12 个)
两轴交叉 + 关键旗标,详细分支表见 `docs/story-bible.md`。

### 5.3 两个隐藏结局
1. **"鉴定师"** —— 玩家在某一刻认出某件物品的真正来历,从而看穿整个世界的循环(要求:全程保持高证据充分度的鉴定,即"真的在认真看")
2. **"关门"** —— 一言不发,把店门锁上,走出去。**不赚一分钱,不卖给任何人。** 这是反战主题的最终表达:退出循环本身,就是唯一的胜利

### 5.4 基调纪律(写作时必须遵守)
- ✅ 幽默来自**官僚文书的荒谬**、**口号的自相矛盾**、**顾客的自欺**、**主角日志里的冷话**
- ❌ 不把创伤搞笑化;不把战争浪漫化;不给玩家"打一场漂亮仗"的机会
- ❌ 不写"好人坏人";只写"各自都很有道理的人"
- ✅ 每一个离谱的幽默点,后面都要跟着一个安静的、让人难受的后果

> 例:"签名处请签您的姓名,若您不识字,请画一个十字。若您认为十字是异教符号,请画一个圆。若您认为圆是异教符号,请按铃叫工作人员。我们已不提供工作人员。" —— 笑完,你会想起来为什么没有工作人员了。

## 6. 美术方向:PS1 滤镜

### 6.1 视觉目标
**不是"复古游戏",是"一卷从废墟里挖出来的录像带"。**

### 6.2 技术清单(Godot 4 实现方式)
| 效果 | 实现 |
|---|---|
| 低内部分辨率 | `SubViewport` 设为 320×240 或 480×270,再整数倍放大到窗口 |
| 顶点吸附(抖动) | 顶点着色器里把 clip space 坐标量化: `pos = floor(pos / w) * w` |
| 无透视修正纹理 | 顶点着色器 `noperspective` 等价写法:传 `uv * w`,片元里除以插值后的 `w` |
| 色阶量化 | 全屏着色器: `color = floor(color * 32.0) / 32.0` |
| 有序抖动 | 4×4 Bayer 矩阵加在量化之前 |
| 扫描线 / 暗角 / 色偏 | 全屏后期:正弦扫描线 + 径向暗角 + RGB 轻微偏移 |
| 纹理过滤 | 全部 `TEXTURE_FILTER_NEAREST`,禁止 mipmap 平滑 |

### 6.3 调色板
**铅灰 + 烛油黄 + 医院绿 + 血锈红**。刻意避开霓虹赛博朋克 —— 这是"核冬天后的宗教废土",不是"高科技低生活"。

## 7. 界面方向

### 7.1 主界面(参考《深空当铺:可能是偷的》)
**已完成实测分析,详见 `docs/ref-analysis.md`。** 关键结论:
- 官方 18 张截图**不含主菜单**,全部是游戏内界面 → 主菜单由我们按其「语言」自行设计
- **直接借鉴的 7 条**:左上角常驻「天数 + 租金倒计时 + 金钱」/ 纸张笔记本式浮动窗口承载参考资料 / 鉴定四段式(工具→对照手册→判定→揭穿)/ 估价带浮动区间 `615 (550~680)` / 道德转折点清空 HUD 只留选择 / 单一固定空间不切场景 / 底部固定功能键
- **刻意不借鉴**:霓虹赛博配色、像素美术、它的三色按钮
- ⚠️ 最重要的一条吸收:**物品数值必须带误差区间**,因为「鉴定精度」这一概念只有具象化成一个区间才有意义

### 7.2 本作界面清单
1. **主菜单** —— 背景是打烊后的店铺实景,蜡烛在烧,菜单像贴在墙上的纸条
2. **柜台界面**(主玩法)—— 左:物品与鉴定工具;中:客人;右:判断与开价
3. **背包/货架网格** —— 拖拽格子,物品有尺寸、价值、真伪标记
4. **日志/结算** —— 打字机字体,纸质报表质感(Papers, Please 的日报)
5. **结局界面** —— 一页纸,一句话,一个数字

## 8. 实现顺序(M = 里程碑)

**原则:先能玩,再好看。绝不先做美术。**

| 里程碑 | 内容 | 验收 |
|---|---|---|
| **M0** ✅ 已完成 | 灰盒场景 + 证件审核循环(临时占位玩法) | 能玩一轮,有结算 |
| **M1** | 鉴定循环:物品属性、工具、证据充分度、客人耐心 | 能对一件物品做鉴定并承担后果 |
| **M2** | 背包格子:工具与商品争位(核心机制落地) | 开门前整理会让人纠结 |
| **M3** | 经营结算:租金递增、燃料、四派系声望 | 会真的感到"钱不够" |
| **M4** | PS1 滤镜 + 调色板 | 截图一眼看出风格 |
| **M5** | 叙事与多结局:客人事件、日志、双轴结局矩阵 | 能通关并打出至少 3 个不同结局 |

## 9. 待用户确认的关键决策
1. **游戏名**(暂用《铅之圣咏》)
2. **时长目标**:一周目 2~4 小时?还是更短(1 小时纯原型)?
