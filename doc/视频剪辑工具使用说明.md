# 视频剪辑工具 - 使用说明

## 🎯 核心特性

这是一个**完全基于浏览器原生 API** 的视频处理工具，无需任何外部库或服务器。

### ✅ 优势

- **零依赖**: 不需要 FFmpeg.wasm 或任何 CDN 资源
- **无跨域问题**: file:// 协议直接打开即可使用
- **即开即用**: 双击 HTML 文件立即启动
- **完全本地**: 所有处理在浏览器完成，文件不上传
- **体积小**: 整个工具只有一个 JS 文件

### ⚠️ 限制

- 输出格式主要为 **WebM** (现代浏览器原生支持)
- 处理速度取决于浏览器性能
- 某些高级功能（如字幕烧录）不支持

---

## 📖 功能说明

### 1️⃣ ✂️ 裁剪视频

**功能**: 按时间范围裁剪视频片段

**使用步骤**:
1. 上传视频文件
2. 播放到起始位置，点击"▶ 开始=当前"
3. 播放到结束位置，点击"⏸ 结束=当前"
4. 点击"🚀 开始处理"

**输出格式**: WebM (VP9 + Opus)  
**处理时间**: 实时播放速度（5分钟视频需要5分钟）

---

### 2️⃣ 🔄 格式转换

**功能**: 将视频转换为 WebM 格式

**使用步骤**:
1. 选择"🔄 格式转换"模式
2. 上传视频文件
3. 调整视频码率（默认 2.5 Mbps）
4. 调整音频码率（默认 128 kbps）
5. 点击"开始处理"

**输出格式**: WebM  
**适用场景**: 网页播放、减小文件大小

---

### 3️⃣ 📸 视频截图

**功能**: 从视频中提取单帧图片

**使用步骤**:
1. 选择"📸 视频截图"模式
2. 上传视频文件
3. 在预览窗口播放到想要的位置
4. 点击"使用当前播放时间"按钮
5. 选择图片格式（PNG/JPEG/WebP）
6. 调整图片质量（0.1-1.0）
7. 点击"开始处理"

**输出格式**: PNG（无损）、JPEG（压缩）、WebP（高效）  
**处理时间**: 瞬间完成

**提示**: 
- PNG 适合需要透明背景或高质量的场景
- JPEG 适合照片，文件更小
- WebP 提供最佳压缩比

---

### 4️⃣ 🎵 提取音频

**功能**: 从视频中提取音频轨道

**使用步骤**:
1. 选择"🎵 提取音频"模式
2. 上传视频文件
3. 设置起始和结束时间
4. 点击"开始处理"

**输出格式**: WebM Audio (Opus 编码)  
**处理时间**: 实时播放速度

**适用场景**: 提取背景音乐、对话、音效等

---

### 5️⃣ 🔇 静音视频

**功能**: 去除视频中的音频轨道

**使用步骤**:
1. 选择"🔇 静音视频"模式
2. 上传视频文件
3. 设置时间范围
4. 点击"开始处理"

**输出格式**: WebM（仅视频）  
**适用场景**: 制作无声视频、替换背景音乐前的准备

---

### 6️⃣ ⚡ 变速播放

**功能**: 加速或减速视频播放

**使用步骤**:
1. 选择"⚡ 变速播放"模式
2. 上传视频文件
3. 设置时间范围
4. 选择播放速度倍率：
   - 0.25x = 1/4 慢速
   - 0.5x = 1/2 慢速
   - 1.0x = 正常速度
   - 2.0x = 2倍速
   - 4.0x = 4倍速
5. 点击"开始处理"

**输出格式**: WebM  
**处理时间**: 根据倍率调整（2倍速 = 时长减半）

**适用场景**: 延时摄影、快速浏览、慢动作分析

## 💡 使用技巧

### 时间控制

- **精确输入**: 直接在"开始时间"和"结束时间"输入框输入秒数
- **播放标记**: 使用播放器播放到目标位置，点击按钮快速标记
- **完整时长**: 点击"📏 完整时长"按钮选择整个视频

### 提高处理速度

1. **减小时间范围**: 只处理需要的片段
2. **降低码率**: 格式转换时使用较低的码率
3. **使用现代浏览器**: Chrome/Edge 性能通常更好

### 文件格式说明

**WebM 格式优势**:
- ✅ 开源免费
- ✅ 浏览器原生支持
- ✅ 优秀的压缩比
- ✅ 适合网页播放

**播放兼容性**:
- ✅ Chrome, Firefox, Edge, Opera
- ✅ Android 设备
- ⚠️ Safari 部分支持
- ❌ 老旧设备可能不支持

**转换为 MP4**（需要其他工具）:
```bash
# 使用 FFmpeg 命令行工具
ffmpeg -i input.webm -c:v libx264 -c:a aac output.mp4
```

## 🐛 常见问题

### Q: 为什么输出是 WebM 格式？

**A**: WebM 是浏览器原生支持的编码格式，不需要外部库。如需 MP4 格式，可以：
1. 使用桌面软件（如 HandBrake）转换
2. 使用在线转换服务
3. 使用 FFmpeg 命令行工具

### Q: 处理大文件时浏览器卡顿怎么办？

**A**: 
- 关闭其他标签页释放内存
- 将视频分段处理
- 使用性能模式（Windows: 最佳性能）

### Q: 为什么没有字幕烧录功能？

**A**: 字幕烧录需要复杂的文本渲染，浏览器原生 API 难以实现高质量效果。建议使用专业工具：
- 桌面端: FFmpeg, HandBrake
- 在线: Kapwing, Clideo

### Q: 可以处理 4K 视频吗？

**A**: 理论上可以，但：
- 需要大量内存（建议 16GB+）
- 处理时间很长
- 可能导致浏览器崩溃
- 建议先降低分辨率再处理

### Q: 为什么变速功能音调会改变？

**A**: 浏览器 playbackRate 同时改变视频和音频速度，因此会影响音调。专业的变速保持音调需要复杂的 DSP 算法，超出了本工具范围。

## 🎓 技术实现

本工具使用以下浏览器原生 API：

```javascript
// 视频录制
MediaRecorder API

// 帧处理
Canvas 2D Context

// 音频处理
Web Audio API (AudioContext, MediaElementSource)

// 流处理
MediaStream, MediaStreamTrack

// 文件处理
File API, Blob, URL.createObjectURL
```

**无需依赖**:
- ❌ FFmpeg.wasm
- ❌ CDN 资源
- ❌ Node.js
- ❌ WebAssembly（自定义）
