# 两站优化第一批：范围与验收

用户批准依据：2026-10-08「按照你说的处理一下」。本轮不 commit、不 push、不接支付、不锁现有免费工具、不发布虚构案例或收益。

## 隔离与部署

本地工作区已有大量未提交 UI/游戏变更，不覆盖、不重置、不整体同步。基于 SSH 拉取的生产文件在 `C:/Users/admin/AppData/Local/hermes/cache/scratch/site-improvements-20261008/stage` 工作，基线在同级 `baseline`，逐文件计算 diff。部署前校验远端仍等于基线，备份到 webroot 外，只更新本轮文件；冲突停止该文件部署。上线后读回文件哈希和 HTTP 结果，留可执行回滚。

## 交付与验收

1. AI 接口：请求大小与输入校验、可信代理取 IP、IP 短时限流/日请求额度、全站并发与持久化每日调用次数上限、请求取消与超时释放、不向用户暴露密钥/上游错误。次数上限是成本风险防护，不声称精确人民币预算。默认不得造成免费功能全停；不在真实生产执行生成测试，不触发真实 AI 费用。隔离 HTTP 测试覆盖无效请求、429、并发释放、状态持久化、视频查询成本边界。
2. 内容：法线页明确常见 OpenGL Y+ / DirectX Y- 的约定，清理草稿痕迹，保留语境/实测边界；Shader 页说明只做规则转换，不承诺跨引擎自动编译与行为等价。回归测试防止文案再次误导。
3. 序列帧：现有切图免费；补安全可预测的批量命名、ZIP、元数据与 Unity/UE 导入说明或真正可用导入脚本，不能把通用 JSON 称为引擎可直接导入配置。保留单图下载、原预览；检查边界、文件名安全、ZIP 文件实际内容和浏览器导出。
4. 商业入口：专业任务优先的首页入口；新增真实服务/产品意向页，列交付范围、尚未开售状态、需求模板与论坛链接，不虚构现有产品/客户案例。不添加未经确认的价格、不显示假购买按钮，不公开收集个人联系信息。
5. 论坛：给 test 测试域名加 X-Robots-Tag: noindex, nofollow 并验证 HTML/PHP 响应；不阻断正式站、不改用户/帖子、不重做现有分类。反馈入口使用现有 TA 分区，暂不冒用管理员发布讨论。
6. 验证：代码变更严格 RED-GREEN；自动化测试、独立审查、实际浏览器点击及 ZIP 下载内容校验；工具站 API 重启健康检查，所有既有站点 HTTP 回归。浏览器或部署阻塞必须注明，不以静态检查替代交互验收。

## 后续，不混入本轮

完整会员/支付、现金游戏、第三方资源商城、大课程、批量 AI SEO 文章、删除论坛分区、大规模视觉重做。精确按人民币的预算需真实单价/账单后才能配置，服务报价由用户确认。

已知行为变化（需用户确认是否接受）：

- 生产原实现允许在供应商声明 `fallback` 时自动跨供应商转发；现在默认只使用用户选定的模型，不自动升级、不跨供应商，失败直接返回错误。同类供应商内部降级需显式程序选项且供应商声明 `fallback` 才生效。
- 分钟额度改为只在实际发起上游请求时扣减；另加一层约 4 倍上限的请求级宽限，防止无效请求耗尽真实额度。

限制：无供应商真实账单/单价，额度仅按调用次数计，不声称精确费用；未配置告警通知；序列帧产物是通用图片+JSON，不是引擎原生资源，仍需手动导入；服务页仅生成需求文本，未接支付、未建立接单流程。
