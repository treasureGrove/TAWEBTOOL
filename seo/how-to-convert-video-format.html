视频格式转换：MP4、WebM 等格式互转教程

2026-08-24

引言

视频格式转换是常见的需求，例如将 WebM 转换为 MP4 以便在更多设备上播放，或将大文件压缩为 WebM 用于网页。本教程将指导你使用多种工具进行格式转换。

使用 HandBrake（图形界面）

HandBrake 是一款免费开源的视频转码工具。

步骤 1：下载安装

从 handbrake.fr 下载并安装。

步骤 2：导入视频

打开 HandBrake，点击“文件”按钮选择源视频。

步骤 3：选择输出格式

在“输出设置”中，选择容器格式（如 MP4、MKV、WebM）。

步骤 4：调整视频编码

  • 视频编码器：H.264、H.265、VP9 等。
  • 质量：使用恒定质量滑块或指定比特率。
  • 分辨率、帧率等可调整。

步骤 5：开始转换

设置输出路径，点击“开始编码”。

使用 FFmpeg（命令行）

FFmpeg 是最强大的多媒体处理工具。

安装

从 ffmpeg.org 下载，或使用包管理器安装。

基本转换命令

将 MP4 转换为 WebM（VP9 编码）：

```bash

ffmpeg -i input.mp4 -c:v libvpx-vp9 -c:a libopus output.webm

```

将 WebM 转换为 MP4（H.264 编码）：

```bash

ffmpeg -i input.webm -c:v libx264 -c:a aac output.mp4

```

参数说明

  • `-c:v` 指定视频编码器。
  • `-c:a` 指定音频编码器。
  • 可添加 `-crf` 控制质量（0-51，越小质量越高）。
  • `-b:v` 设置视频比特率。

使用在线转换工具

如 CloudConvert、Convertio、Zamzar 等，上传视频即可转换，适合小文件。

使用视频编辑软件

Adobe Premiere、Final Cut Pro、DaVinci Resolve 等均可导出不同格式。

格式选择建议

  • **MP4 (H.264)**：兼容性最好，适用于大多数场景。
  • **WebM (VP9)**：开源格式，适合网页，文件较小。
  • **MKV**：多轨容器，适合存储。
  • **MOV**：苹果生态常用。

注意事项

  • **版权**：确保你有权转换视频。
  • **质量与大小平衡**：根据目标平台选择编码参数。
  • **硬件加速**：使用 GPU 加速可提高速度，如 FFmpeg 中使用 `-hwaccel`。

总结

视频格式转换工具多样，HandBrake 适合图形界面用户，FFmpeg 功能强大且可自动化，在线工具方便快捷。根据需求选择合适的工具。

常见问题

如何将视频转换为 GIF 动图？

使用 FFmpeg 命令：`ffmpeg -i input.mp4 -vf "fps=10,scale=320:-1" output.gif`，可调整帧率和尺寸。

转换后视频没有声音怎么办？

检查音频编码设置，确保输出容器支持音频编码。使用 FFmpeg 时明确指定 `-c:a`，如 `-c:a aac`。

如何批量转换多个视频？

使用 FFmpeg 的批处理脚本，如 Windows 的 for 循环或 Linux 的 shell 脚本，遍历文件并执行转换命令。

转换速度很慢，如何加速？

使用硬件加速编码，如 Intel QSV、NVIDIA NVENC。在 FFmpeg 中指定 `-c:v h264_nvenc` 等。或降低输出分辨率、使用更快的编码预设。

WebM 和 MP4 哪个更好？

WebM 是开源格式，在相同质量下通常文件更小，但兼容性不如 MP4。对于网页，WebM 是好选择；对于通用性，MP4 更安全。
