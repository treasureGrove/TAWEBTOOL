图片压缩与格式转换：WebP 及常用格式指南

2026-08-24

引言

图片压缩和格式转换是优化网页加载速度和节省存储空间的关键。WebP 格式由 Google 开发，提供有损和无损压缩，通常比 JPEG 和 PNG 更高效。本教程将指导你使用不同工具进行图片压缩和格式转换。

使用在线工具

TinyPNG / TinyJPG

  1. 访问 TinyPNG 网站。
  2. 拖放或上传图片（支持 PNG、JPG）。
  3. 自动压缩并显示下载按钮，可批量下载。

    4. Squoosh

    1. 访问 squoosh.app。
    2. 点击“选择图片”导入。
    3. 选择输出格式（如 WebP、AVIF）。
    4. 调整质量滑块，实时预览压缩效果。
    5. 点击下载。

      6. 使用图像编辑软件

      Adobe Photoshop

      1. 打开图片，选择“文件” > “导出” > “存储为 Web 所用格式（旧版）”。
      2. 选择格式（如 WebP），调整质量、尺寸等参数。
      3. 点击“存储”。

        4. GIMP

        1. 打开图片，选择“文件” > “导出为”。
        2. 选择文件类型为 WebP，点击“导出”。
        3. 调整质量参数。

          4. 使用命令行工具

          ImageMagick

          转换格式并压缩：

          ```bash

          magick input.jpg -quality 80 output.webp

          ```

          cwebp（WebP 编码器）

          安装 libwebp 后使用：

          ```bash

          cwebp -q 80 input.png -o output.webp

          ```

          Python Pillow

          ```python

          from PIL import Image

          img = Image.open('input.jpg')

          img.save('output.webp', 'webp', quality=80)

          ```

          压缩参数建议

          • **网页图片**：有损 WebP 质量 75-85 通常视觉无损。
          • **透明图片**：使用 WebP 无损模式或 PNG 压缩。
          • **照片**：JPEG 质量 80 与 WebP 质量 80 相比，WebP 文件更小。

          注意事项

          • **浏览器兼容性**：WebP 已获主流浏览器支持，但旧版浏览器可能不兼容。可提供 fallback。
          • **元数据保留**：某些工具会删除 EXIF 信息，根据需要选择保留。
          • **批处理**：命令行工具适合批量处理。

          总结

          选择合适的工具和方法可以大幅减少图片大小，加快网页加载速度。WebP 是当前推荐的格式，但根据需求也可考虑 AVIF 等更现代格式。

常见问题

WebP 和 JPEG 哪个更好？

在相同质量下，WebP 通常比 JPEG 小 25-35%，支持透明度和动画，是现代网页的首选。

如何批量转换图片为 WebP？

可以使用命令行工具如 cwebp 配合循环脚本，或使用 Squoosh 的批量功能、ImageMagick 的 mogrify 命令。

压缩后图片质量下降明显怎么办？

提高质量参数，如将 WebP 质量从 70 提高到 85，或使用无损压缩。

如何将 WebP 转换回 PNG 或 JPG？

使用图像编辑软件（如 GIMP、Photoshop）打开后另存为所需格式，或使用 ImageMagick 命令：`magick input.webp output.png`。

是否有必要使用 AVIF 格式？

AVIF 压缩率更高，但编码速度较慢且工具支持较少。如果目标环境支持，可考虑使用。
