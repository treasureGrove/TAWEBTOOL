色调映射：HDR到LDR的转换与ACES应用

2026-08-24

什么是色调映射

色调映射（Tone Mapping）是将高动态范围（HDR）图像转换为低动态范围（LDR）显示设备可显示的过程。HDR 场景包含远超显示器能力的亮度范围（如太阳 vs 阴影），色调映射算法通过压缩亮度，同时保留细节和色彩，模拟人眼对高对比度场景的适应。它广泛应用于摄影、电影和实时渲染。

为什么需要色调映射

渲染管线通常在线性空间计算 HDR 光照，亮度值可能从 0 到数百甚至更高，而普通显示器只能显示 0 到 1（或 0-255）。直接将 HDR 值截断会导致亮部过曝、暗部死黑。色调映射将广泛的亮度范围压缩到显示器可显示的范围，同时保持视觉真实感，避免细节丢失。

常用色调映射算法

Reinhard 色调映射

经典算法：`L_display = L / (1 + L)`。它将无限亮度映射到 [0,1]，简单高效，但可能导致对比度降低和颜色饱和度变化。

Filmic 色调映射

模拟电影胶片的响应曲线，提供更好的高光过渡和色彩保持。常见变体如 ACES Filmic、Uncharted 2 等。

ACES 色调映射

ACES（Academy Color Encoding System）是电影行业标准，其色调映射曲线被广泛采用。它通过复杂的拟合曲线实现电影级效果，保留高光细节和色彩准确性。在 Unity 和 Unreal 中，ACES 是默认选项之一。

其他算法

  • **电影级色调映射**：自定义曲线，提供艺术控制。
  • **局部色调映射**：根据局部区域调整对比度，较复杂，较少用于实时。

在渲染管线中的应用

实时渲染中，色调映射通常作为后处理步骤，在 HDR 渲染之后、伽马校正之前执行。流程：

  1. 场景渲染到 HDR 缓冲。
  2. 应用色调映射将 HDR 转换为 LDR。
  3. 进行伽马校正（线性到 sRGB），输出到屏幕。

    4. 在 Unity 中，使用 Post Processing 包可以启用色调映射，选择 ACES 或 Neutral 等模式。Unreal 中，在后期处理体积中设置 Tone Mapper。

    色调映射与曝光

    色调映射通常与曝光控制结合。曝光模拟相机光圈或人眼适应，在色调映射前调整 HDR 图像的亮度。例如，自动曝光根据场景平均亮度调整，避免过暗或过亮。

    常见问题

    色调映射和伽马校正有什么区别？

    色调映射将 HDR 压缩到 LDR 范围，是亮度的非线性映射；伽马校正则是线性与 sRGB 之间的编码转换，两者在管线中按顺序执行。

    为什么推荐使用 ACES 色调映射？

    ACES 提供电影级效果，高光过渡自然，色彩保持良好，已成为行业标准。

    不进行色调映射会怎样？

    HDR 值会截断，导致亮部过曝、暗部丢失细节，画面失真。

    移动端可以使用色调映射吗？

    可以，但色调映射增加后处理开销，需根据性能评估。移动端可以使用简化的 Reinhard 或近似曲线。

    如何调整色调映射的效果？

    可以调整曝光、白点、曲线参数等，或选择不同算法。在 Unity 中，Post Processing 提供多个参数。
