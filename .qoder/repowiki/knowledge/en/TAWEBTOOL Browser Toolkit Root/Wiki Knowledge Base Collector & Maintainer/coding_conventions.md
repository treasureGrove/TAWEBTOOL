- Shell entry points set `set -euo pipefail`, resolve `SCRIPT_DIR`/`SITE`, source `/etc/profile` and `~/.bashrc` defensively, then load `.env` with `set -a` so downstream Node scripts inherit variables.
- Environment variables follow a `WIKI_*` prefix with documented defaults (e.g. `WIKI_AI_MODEL=${WIKI_AI_MODEL:-deepseek-v4-flash}`) and are read both from the shell wrapper and inside the Node scripts via a shared `loadDotEnv` helper.
- External API calls go through a single `callAiJson` function that posts to `${AI_BASE_URL}/chat/completions` with `response_format: { type: 'json_object' }` and `thinking: { type: 'disabled' }`, and callers parse the returned JSON with `parseJsonObject` as a fallback.
- Every entry object carries stable identity fields (`id` derived from `sha1(url)` via `idFor`, plus `sourceId`/`sourceTitle`) and provenance metadata (`filterReason`, `relevanceScore`, `filterConfidence`, `quality`, `aiModel`, `updatedAt`) so merges and diffs stay deterministic.
- Markdown content is assembled section-by-section using fixed headings ('自动归纳', '原文摘录', '文章阐述', 'TA 视角', '元信息') and later mutated in-place via `replaceMarkdownSection(heading, lines)`, keeping structure machine-editable.
- All I/O errors are caught and logged with a `[wiki]` or `[wiki-mail]` prefix while allowing the pipeline to continue (non-fatal `console.warn`), so a single failing source does not abort the whole run.
