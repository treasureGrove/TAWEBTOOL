Requires a `.env` at repository root (or `DEEPSEEK_API_KEY`/`WIKI_AI_API_KEY` env var) and optionally `GITHUB_TOKEN`; the maintainer script auto-reads `WIKI_AI_MODEL`, `WIKI_MIN_RELEVANCE_SCORE`, `WIKI_NOTIFY_EMAIL`, etc. Run `./scripts/run_wiki_collect.sh` to collect+write entries, or `./scripts/opencode_wiki_maintainer.sh` for the full pipeline (collect → digest → opencode review → git sync → mail). Models must be fetched separately via `./scripts/fetch_models.sh` before runtime code can use them.
