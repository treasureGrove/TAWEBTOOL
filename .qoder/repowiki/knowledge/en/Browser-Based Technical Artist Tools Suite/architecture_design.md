- **Single-page launcher** (`index.html`) renders the global sidebar via `js/menu.js` and links to each tool under `tools_html/`, which is the only place that declares `<script src="../js/menu.js">`.
- **Centralized routing contract**: `MENU_DATA` in `js/menu.js` is the single source of truth for every tool's label, href, category icon, and search keywords; both the sidebar and the top search bar derive from it, so adding a tool requires editing only this array.
- **Two bootstrap modes**: most tools are independent HTML+JS pairs (e.g. `ai_upscale.html` → `ai_upscale.js`); a subset (`chatgpt`, `hdr_editor`, `physics_light`, `shader_library`, `model_previewer`, `ps_online`, `video_cut`, `ai_draw`) opt into the shared workbench by placing their markup inside a `<div id="panel" data-local-tool="...">`, which `js/local_workbench.js` detects and bootstraps by calling a convention-named `initXxxTool(host)` function exposed on `window`.
- **Shared styling contract**: every page imports `css/common.css` for the sidebar/layout chrome plus its own per-tool CSS; theme tokens live in `tokens.json` consumed by all stylesheets.
- **Shared runtime layer**: AI/video modules load ONNX Runtime Web and FFmpeg.wasm from `third_part/onnxruntime-web/1.17.1/` and `third_part/ffmpeg-wasm/` respectively, avoiding per-tool duplication and enabling GPU/CPU fallback paths.
