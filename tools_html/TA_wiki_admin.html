同步操作

支持从远端拉取并合并到本地，也支持将本地最新条目推送到远端。

  • 建议在远端服务器创建专用 API Key，并限制为“知识库读/写”最小权限。
  • 远端返回格式建议为数组：`[{title,category,tags,summary,content,id}]`。
  • 跨域失败（CORS）时，请在远端服务放行当前域名，或通过后端代理转发。
