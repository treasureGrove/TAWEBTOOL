UE / Unity 色彩空间速查

Unreal Engine
• 纹理默认 sRGB → 引擎自动转 Linear 用于光照计算
• ORM/RMA 贴图需关闭 sRGB（存储 Linear 数据）
• 输出到显示器时自动 Linear → sRGB
Unity
• Linear 工作流：纹理导入时勾选 sRGB
• Gamma 工作流：所有贴图按原样采样
• HDRP 强制 Linear，URP 可选
常见坑
• 法线/ORM/AO 贴图误开 sRGB → 颜色偏移
• UI 贴图在线性空间下变暗（忘记开 sRGB）
• 跨引擎迁移材质时 Gamma 不一致
